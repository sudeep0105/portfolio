Job Application Management Full-Stack Development

JobTrack — Job Application Tracker

The Challenge

Keeping track of job applications, interviews, company details, and follow-ups across different places can quickly become difficult. JobTrack brings everything together in one dashboard so users can organize applications and monitor their job-search progress.

Technical Approach

Built a responsive React (Vite) frontend and Java Spring Boot REST API. Secured registration and login with JWT authentication and BCrypt password hashing. Used Spring Data JPA and MySQL to store accounts and applications while keeping each user's data private. Users can create, view, edit, delete, search, filter, and sort applications, with dashboard summaries showing application progress.

Machine Learning Healthcare Tech

Classification of Sleep Patterns & Disorders

The Challenge

Traditional sleep diagnostic methods like Polysomnography (PSG) are often inconvenient and expensive for patients. This project explores using machine learning to classify sleep disorders directly from health and lifestyle data sourced from Kaggle — making diagnosis more accessible.

Technical Approach

Implemented Ensemble Learning techniques — specifically Stacking and Voting Classifiers — to enhance prediction accuracy and model robustness. This outperformed single-model baselines like KNN and SVM by leveraging the strengths of multiple learners.
